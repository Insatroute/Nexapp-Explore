The links between those nodes: which pair a link joins, its cost, and whether it is currently up.

## What you can do here

### Actions

- **Create net link** — Adds a link by hand, between two existing nodes. Like nodes, these are normally discovered by the parser.
- **Delete net link** — Removes the link from the graph. Nothing on the network changes — this graph is a report of what was found, not a configuration that is pushed.
- **Edit net link** — Changes a link's cost or status. Cost is what a routing protocol weighs, so this is not just a label.

### Reading and lookups

- **Browse and search net links** — The links between nodes, from `/network-topology/link/` — which pair each joins, its cost, and whether it is currently up.
- **Browse and search net nodes** — The nodes a link can join, for the same reason.
- **Browse and search net topologies** — The parsed topologies a record here can belong to, so the form can offer a choice rather than an id.
- **Browse and search organizations** — The organization list — what the scope picker narrows the page by, and what fills the Organization field on its forms. Almost every record in the controller is organization-scoped, which is why this call appears on so many pages.

**Opens:** `LinkDrawer` · `useNetTopologies` — some actions above are performed in these.
