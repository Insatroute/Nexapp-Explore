A disclosure, not a link: there is no combined log viewer, only these four records — the same shape as the Monitoring entry above.

`Logs` is a disclosure in the sidebar — it opens, it does not navigate. It covers:

- [Access log](/controller/reports-logs/logs/access-log) — Sign-ins, sign-outs and failed attempts.
- [Activity log](/controller/reports-logs/logs/activity-log) — Who changed what.
- [Device log](/controller/reports-logs/logs/device-log) — Syslog from the devices themselves.
- [Firmware log](/controller/reports-logs/logs/firmware-log) — Upgrade lifecycle events, synced from each device's own `/etc/ns-update-audit.jsonl`.

<Callout type="info">The note above is authored, from the `NAV` array in `Sidebar.jsx`.</Callout>
