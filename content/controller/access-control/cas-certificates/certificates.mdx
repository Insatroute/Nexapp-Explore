Certificates issued from those CAs, each showing which authority signed it and whether it is still valid.

Each record belongs to an organization.

<Callout type="info">Served by the shared `PkiHub` component via the `/pki/:tab` route. Facts below describe that component, which renders several tabs.</Callout>

## What you can do here

### Actions

- **Delete resource** — Removes a certificate via `DELETE /api/v1/controller/cert/<id>/`.
- **Edit resource** — Creates and edits a certificate through the shared resource form. Fields: Name, Organization, CA.

### Reading and lookups

- **Browse and search resource** — Lists certificates from `GET /api/v1/controller/cert/`, with columns Name, Organization, Authority, Key length, Digest, Valid until, State.

**Opens:** `ResourceTable` — some actions above are performed in it.
