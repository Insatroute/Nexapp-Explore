`CAs & Certificates` is a disclosure in the sidebar — it opens, it does not navigate. It covers:

- [Certification Authorities](/controller/access-control/cas-certificates/certification-authorities) — The CAs the controller issues from.
- [Certificates](/controller/access-control/cas-certificates/certificates) — Certificates issued from those CAs, each showing which authority signed it and whether it is still valid.
