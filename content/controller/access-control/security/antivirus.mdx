Which protocols are scanned, how large a file will still be inspected, and whether hits are quarantined.

Scoped like the rest of Security: fleet-wide, or narrowed to an organization or a single device.

<Callout type="info">Served by the shared `SecurityHub` component via the `/security/:tab` route. Facts below describe that component, which renders several tabs.</Callout>

## What you can do here

### Actions

- **Delete resource** — Removes a policy via `DELETE /api/v1/security/antivirus/<id>/`.
- **Edit resource** — Creates and edits a policy through the shared resource form. Fields: Scan HTTP, Scan SMTP, Scan FTP, Scan on access, Max file size (MB), Quarantine, Auto-update signatures.

### Reading and lookups

- **Browse and search resource** — Lists policies from `GET /api/v1/security/antivirus/`, with columns Name, Max file (MB), Scope, State.

**Opens:** `ResourceTable` — some actions above are performed in it.
