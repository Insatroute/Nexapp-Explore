Named sets of addresses, reused by the policies above instead of repeating a list in each one. Unlike the other tabs this is a plain organization-owned record — there is no fleet-wide/device scope and no enabled state.

Scoped like the rest of Security: fleet-wide, or narrowed to an organization or a single device.

<Callout type="info">Served by the shared `SecurityHub` component via the `/security/:tab` route. Facts below describe that component, which renders several tabs.</Callout>

## What you can do here

### Actions

- **Delete resource** — Removes a address group via `DELETE /api/v1/security/address-group/<id>/`.
- **Edit resource** — Creates and edits a address group through the shared resource form. Fields: Addresses, Description.

### Reading and lookups

- **Browse and search resource** — Lists address groups from `GET /api/v1/security/address-group/`, with columns Name, Description, Organization.

**Opens:** `ResourceTable` — some actions above are performed in it.
