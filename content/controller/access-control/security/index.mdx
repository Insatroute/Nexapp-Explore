`Security` is a disclosure in the sidebar — it opens, it does not navigate. It covers:

- [Instashield IP](/controller/access-control/security/instashield-ip) — IP reputation blocking and brute-force protection: drop traffic from known-bad addresses, and ban a source after a set number of failed attempts.
- [IPS](/controller/access-control/security/ips) — Intrusion prevention.
- [Antivirus](/controller/access-control/security/antivirus) — Which protocols are scanned, how large a file will still be inspected, and whether hits are quarantined.
- [AntiSpam](/controller/access-control/security/antispam) — Mail filtering, pointed at a relay host with optional SASL authentication.
- [Web Filter](/controller/access-control/security/web-filter) — Category-based web filtering, plus custom rules for anything the categories do not cover.
- [Address Groups](/controller/access-control/security/address-groups) — Named sets of addresses, reused by the policies above instead of repeating a list in each one.
- [Profiles](/controller/access-control/security/profiles) — Security profiles — the bundle a policy applies.
- [Policies](/controller/access-control/security/policies) — The security policies themselves, tying the profiles above to the traffic they govern.
