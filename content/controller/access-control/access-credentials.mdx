How the controller logs in to devices in order to push configuration — the SSH credentials themselves. A credential has a connection type and an organization, and can be set to attach automatically to new devices in that organization rather than being applied by hand.

SSH keypairs are generated here, so a private key never has to be pasted in from elsewhere.

## What you can do here

### Actions

- Create credential
- Delete credential
- Edit credential
- **Generate ssh keypair** — Creates a keypair in place, so the private half is never carried in from somewhere else.

### Reading and lookups

- Browse and search credentials
- Browse and search groups
- Browse and search organizations

**Opens:** `CredentialFormModal` · `useScopeOrg` — some actions above are performed in these.
