Replaces the old "Authentication" entry, which pointed at the app index and named the protocol nowhere.

`TACACS+` is a disclosure in the sidebar — it opens, it does not navigate. It covers:

- [Servers](/controller/access-control/tacacs/servers) — The TACACS+ servers this controller runs: what they listen on, whether authentication and accounting are enabled, the deploy mode, and whether the running configuration matches what has been asked for — a pending count means changes are staged but not yet reloaded.
- [Client (login)](/controller/access-control/tacacs/client-login) — The other side: this controller acting as a TACACS+ CLIENT, so administrators sign in to it against a TACACS+ server.
- [Command rules](/controller/access-control/tacacs/command-rules) — Command authorization: which commands a group may or may not run.
- [Device group secrets](/controller/access-control/tacacs/device-group-secrets) — The shared secret each device group uses to talk to TACACS+, and when that secret was last deployed to them.
- [Active sessions](/controller/access-control/tacacs/active-sessions) — Who is logged in through TACACS+ right now: the user, the device, where they connected from, at what privilege level, and how long they have been there.
- [Accounting logs](/controller/access-control/tacacs/accounting-logs) — The TACACS+ command log — every command run, by whom, on which device, at what privilege and from where.

<Callout type="info">The note above is authored, from the `NAV` array in `Sidebar.jsx`.</Callout>
