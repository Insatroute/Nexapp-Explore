The TACACS+ command log — every command run, by whom, on which device, at what privilege and from where. The audit trail that command authorization is written against.

## What you can do here

- **Browse and search TACACS+ accounting** — The command log, from `tacacs/accounting/` — what each user did, on which device, when. Read-only and deliberately so: this is the audit trail command authorization is written against. Rows are aged out by the retention window rather than deleted by hand.
