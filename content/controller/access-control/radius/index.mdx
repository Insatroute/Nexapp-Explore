Who may reach the network, and how they prove it. The two AAA protocols are disclosures rather than a link each to an app index — between them they have twelve admin pages that no menu mentioned.

`RADIUS` is a disclosure in the sidebar — it opens, it does not navigate. It covers:

- [NAS](/controller/access-control/radius/nas) — The RADIUS clients — the network access servers permitted to ask this controller to authenticate a user.
- [Groups](/controller/access-control/radius/groups) — RADIUS user groups — the named buckets that check and reply attributes are attached to, so a rule can be written once for a group instead of per user.
- [Checks](/controller/access-control/radius/checks) — Check attributes: the conditions a RADIUS request must satisfy to authenticate.
- [Replies](/controller/access-control/radius/replies) — Reply attributes: what RADIUS sends BACK once a user has authenticated — the session parameters the NAS then applies.
- [Accounting](/controller/access-control/radius/accounting) — Live and historical RADIUS sessions: who is connected, through which NAS and from which IP and client MAC, when the session started, how long it has run, and how much traffic passed in each direction.
- [Post-auth log](/controller/access-control/radius/post-auth-log) — The authentication log: every attempt and whether it succeeded, with the username, the client and NAS MAC addresses and when it happened.
- [Batch operations](/controller/access-control/radius/batch-operations) — Bulk user creation.
