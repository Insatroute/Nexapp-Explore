The RADIUS clients — the network access servers permitted to ask this controller to authenticate a user. An entry is a shared secret plus the address the request will arrive from, scoped to an organization.

## What you can do here

### Actions

- **Create NAS** — Registers a new client. Until a NAS exists here with the right secret, its authentication requests are refused before any user is even looked up.
- **Delete NAS** — Removes a client. Requests from that address stop being accepted.
- **Edit NAS** — Changes an entry — `PATCH radius-admin/nas/<id>/`. Rotating the shared secret here means rotating it on the device too, or it stops authenticating.

### Reading and lookups

- **Browse and search NAS** — The RADIUS clients, from `radius-admin/nas/`. A row is one network access server allowed to ask this controller to authenticate a user — its address and shared secret, scoped to an organization.
- **Browse and search organizations** — The organization list — what the scope picker narrows the page by, and what fills the Organization field on its forms. Almost every record in the controller is organization-scoped, which is why this call appears on so many pages.
