A disclosure, not a link: monitoring has no landing page of its own, only these three lists — the same shape as the IPAM entry above.

`Monitoring` is a disclosure in the sidebar — it opens, it does not navigate. It covers:

- [WiFi Sessions](/controller/intelligence/monitoring/wifi-sessions) — Wi-Fi association history: which client MAC joined which SSID on which device, the vendor the MAC resolves to, and when the session started and stopped.
- [Metrics](/controller/intelligence/monitoring/metrics) — The metrics being collected from devices.
- [Checks](/controller/intelligence/monitoring/checks) — The checks that decide whether a device counts as healthy — the thing behind the Online / Problem / Offline split on Devices.
