Where devices physically are. A location is a named place owned by an organization, with a type, coordinates and a pincode, and the list shows how many devices sit at each — so a location with none is visible as a candidate for tidying.

Coordinates are what put a device on the fleet map.

## What you can do here

### Actions

- Create location
- Delete location
- Edit location

### Reading and lookups

- Browse and search groups
- Browse and search location records
- Browse and search locations
- Browse and search organizations

**Opens:** `LocationFormDrawer` · `useScopeOrg` — some actions above are performed in these.
